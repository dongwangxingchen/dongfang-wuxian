# DFWX-BRAND-001：赞助页重做

状态：待执行
前置：BASE-001；建议在 AI 和安全底座稳定后实施

## 目标

把赞助页从历史入口调整升级为完整、克制、可信的产品页面，与东方无限整体视觉统一。

## 范围

- 赞助入口位置和返回链；
- 说明层级、文案、金额/方式展示；
- 加载中、失败、无内容和外部跳转；
- 按钮按压反馈、禁用态和重复点击；
- 深色主题、间距、字重、圆角和现有 Token；
- 日志和外部链接安全。

## 禁止

- 不删除用户自愿支持入口；
- 不接入绕过上游付费或平台规则的能力；
- 不把支付凭据写入日志；
- 不在未选定设计方案前大面积改其他页面；
- 不添加未经批准的宿主依赖。

## 验收

- Robolectric/JVM 结构和点击测试；
- 异常状态可恢复；
- 与关于/致谢页面不重复；
- 手机 release 视觉验收；
- 任务卡记录截图/设备/版本/回退点。
