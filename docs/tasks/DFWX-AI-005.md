# DFWX-AI-005：AI 生命周期、日志、HTTPS 和回归门禁

状态：待执行
前置：DFWX-AI-002、DFWX-AI-003、DFWX-AI-004

## 目标

让新版 AI 接入在页面重建、返回、网络失败和流式响应时稳定，并建立不泄露凭据和用户内容的日志边界。

## 允许修改

- AI 宿主桥接、vendor 请求日志链和对应测试；
- AI 任务文档及补丁清单。

## 禁止修改

- 不打印 API Key、Authorization、Cookie、完整请求/响应 body 或用户聊天内容；
- 不绕过 HTTPS 策略；
- 不引入未批准宿主依赖；
- 不通过日志或测试输出泄露 `local.properties`。

## 必须测试

- 进入/退出/返回/重建；
- 空 Provider、失效模型、错误响应和 SSE 中断；
- 取消请求后不回写已销毁页面；
- 外部 HTTP 地址拒绝；
- 日志扫描不出现凭据、完整 body 或 SSE 内容；
- JVM/必要的 fake 集成测试和编译。
