# 东方无限：历史资料归档

> 这里的内容是旧计划、旧研究、旧截图或已经被新计划替代的工作材料。它们保留用于追溯，不是当前实施命令。
>
> 当前实施唯一入口：`../plan/DFWX-MASTER-PLAN.md`

## 目录规则

- `plan/`：旧的长期计划、治理包和阶段路线；
- `tasks/`：旧的专题任务、调查和性能记录；
- `research/`：以后需要单独归档的外部研究或选型材料；
- 归档文件尽量保持原目录结构和原文件名，不添加“最新版、修改版、终版”等后缀；
- 不删除历史证据，不覆盖同名文件；
- 归档后在当前任务卡中只引用结论和相对路径，不要求后续 AI 默认通读全部历史资料。

## 归档标记

每个归档目录应在目录内保留一份 `ARCHIVED.md`，写明：

- 原路径；
- 归档日期；
- 归档原因；
- 当前替代入口；
- 哪些内容仍可作为证据；
- 哪些结论已经被当前源码或 `decisions.md` 取代。

归档不是删除，也不代表其中每条结论都错误；它只表示不能绕过当前总计划直接执行。
