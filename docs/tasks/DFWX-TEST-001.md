# DFWX-TEST-001：高风险链路测试矩阵

## 目标

把高风险链路变成可失败的自动测试和产物检查，而不是靠人工记忆。

## 覆盖范围

URL/重定向/DNS、来源和安装策略、APK 校验、Provider 迁移、AI 日志、下载状态机、进程重建、ADB 状态、WebView/FileProvider、Manifest、备份恢复和 release 产物。

## 规则

每个测试写清前置、输入、预期状态和失败原因；不能把旧截图当测试；手机 release 验收与 JVM 测试分开记录。

## 完成标准

P0/P1 风险各有可失败测试；测试失败会阻止后续任务或发布；测试命令和环境写入任务卡；不做不可逆手机操作。
